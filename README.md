# Nowcast

> 초보자도 딸깍 한 번으로 확인하는 강원랜드 카지노 혼잡 예보 · AI 가이드 서비스
> 강원랜드 × SDU-COSS 바이브코딩 캠프 · 팀 딸깍

## 활용 데이터셋 (공공데이터포털 · 제공기관 (주)강원랜드)

- 일자별 카지노 입장객 현황 (내국인/외국인)
- ARS·모바일 예약 현황
- 카지노발행대비출입현황 (내국인) / 외국인 입장권 발행현황
- 카지노게임현황
- 카지노게임 진행 가이드 시리즈

_(M1~M5 진행하며 실제 활용분으로 갱신 예정)_

## 주요 기능

1. **혼잡 예보 캘린더** — 과거 입장객 데이터 기반 일자별 혼잡 등급(원활/보통/혼잡) 예측
2. **게임 추천** — 좌석 규모 기준 초보자가 앉기 쉬운 게임 순 정렬 + 노쇼율 기반 방문 팁
3. **AI 가이드 챗봇** — 예보·게임 규칙 데이터를 근거로 답하는 첫 방문자 안내 도우미

## 기술 스택

Next.js 14 (App Router) · TypeScript · Tailwind CSS · Recharts · Anthropic API

## 실행 방법

```bash
npm install
cp .env.example .env.local   # 키 입력
npm run dev
```

환경변수:

| 이름 | 용도 |
|---|---|
| `DATA_GO_KR_API_KEY` | 공공데이터포털 인증키 |
| `ANTHROPIC_API_KEY` | AI 가이드 챗봇 |
