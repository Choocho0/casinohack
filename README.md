# Nowcast

> **헛걸음 없는 방문의 시작 — 강원랜드 카지노 실시간 예약 현황 · AI 가이드 서비스**
> 강원랜드 × SDU-COSS 바이브코딩 캠프 · 팀 딸깍

**배포 URL: https://casinohack.vercel.app**

하나의 서비스를 두 가지 화면으로 제공합니다. 접속하면 **웹 페이지**(데스크톱형, 하이원 공식 사이트 디자인 참고)가 먼저 열리고, 우측 상단 토글로 **앱 화면**(모바일형, `/app`)과 자유롭게 전환할 수 있습니다.

## 주요 기능

### 1. 실시간 예약 현황 캘린더
일자별 현황을 원활/보통/혼잡 3등급 히트맵으로 보여줍니다. **8월 10일까지는 일자별 이용자 현황**, **8월 11일부터는 예약 접수 현황**(`예약` 뱃지 표시)으로 구분되며, 날짜를 클릭하면 해당일의 이용자·예약자 수를 확인할 수 있습니다. 예약 기간에는 같은 주에서 가장 여유로운 "이 주의 추천 방문일"도 함께 안내합니다.

### 2. 게임 운영 현황
카지노게임현황 공공데이터 기준 15종 게임을 좌석 규모 순으로 제공합니다. 게임마다 난이도 뱃지(입문/쉬움/보통)·좌석 게이지·한 줄 설명이 붙고, 클릭하면 진행 방법 요약과 함께 **"게임 진행 가이드 영상 시청" 버튼**으로 게임별 유튜브 가이드 영상에 바로 연결됩니다.

### 3. AI 가이드 챗봇 (Nowcast AI)
이용·예약 현황, 게임 좌석 규모, 규칙 요약, 이용 절차를 컨텍스트로 답하는 첫 방문자 안내 도우미입니다. 승률·배팅 전략 질문은 정중히 거절하며, Anthropic API 키가 없거나 호출이 실패해도 스냅샷 데이터 기반 로컬 안내 모드로 동작합니다.

### 4. 이용 안내
카지노 시설 안내도(클릭 시 확대 보기), **ARS 입장순서 신청(033-590-7400)**, 처음 방문 절차 4단계를 웹·앱 양쪽에서 제공합니다.

## 활용한 강원랜드 공공데이터셋 (공공데이터포털 · 제공기관 ㈜강원랜드)

- 내국인 카지노 입장권 발행대비 출입현황 — 일자별 이용자 현황(6월 실데이터)
- 외국인 카지노 입장권 발행대비 출입현황
- 외국인 국가별 일일 카지노 입장현황 — 일자별 외국인 합산 + 실시간 위젯(Open API)
- 내국인 입장권 ARS/모바일 예약현황
- 외국인 입장권 ARS/모바일 예약현황
- 카지노게임현황 — 게임별 테이블·기기 수

> ⚠️ 2026년 7월 이후의 이용자·예약자 수치는 6월 실데이터의 요일 패턴을 기반으로 생성한 **시연용 데모 데이터**입니다 (`scripts/build_live_status.ts`, 시드 고정).

## 데이터 전략 (하이브리드)

원본 CSV를 `scripts/build_snapshot.ts`로 전처리한 `data/*.json` 스냅샷이 모든 화면의 기본 소스입니다. `/api/forecast`가 요청 시 공공데이터 Open API 최신분을 병합하며, API 실패 시 조용히 스냅샷만 사용하므로 **키가 없어도 전체 화면이 동작**합니다.

## 기술 스택

Next.js 14 (App Router) · TypeScript · Tailwind CSS · Anthropic API (claude-sonnet-4-6) · Vercel

## 실행 방법

```bash
npm install
npm run dev        # http://localhost:3000
```

환경변수 (선택 — 없어도 스냅샷으로 전체 동작):

```bash
cp .env.example .env.local
```

| 이름 | 용도 |
|---|---|
| `ANTHROPIC_API_KEY` | AI 가이드 챗봇 (미설정 시 로컬 안내 모드) |
| `DATA_GO_KR_API_KEY` | 공공데이터포털 인증키 (실시간 외국인 위젯·최신분 병합) |
| `DATA_GO_KR_API_URL` | (선택) odcloud 요청주소 — 입장객 최신분 병합용 |

유용한 스크립트:

```bash
npm run snapshot                        # data_raw/*.csv → data/*.json 재생성
npx tsx scripts/build_live_status.ts    # 이용·예약 현황 데이터 재생성
npm run verify                          # 예보 모델 등급 분포 콘솔 검증
```

| `/web` | 웹 페이지 (예약 현황 · 게임 · AI 가이드 · 이용 안내 통합) |
| `/app` | 앱 화면 — 예보 탭 (현황 캘린더) |
| `/games` | 앱 화면 — 게임 탭 |
| `/guide` | 앱 화면 — AI 가이드 탭 |
| `/howto` | 앱 화면 — 이용 안내 탭 |
